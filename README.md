# Ваш агент в MAX 🚀

Подключите [Hermes Agent](https://hermes-agent.nousresearch.com/) к мессенджеру
[MAX](https://max.ru) — и общайтесь со своим ИИ-помощником прямо в чате: он слышит
голосовые, видит фото и видео, присылает карты, стикеры и файлы, умеет кнопки
подтверждения и печатает ответ ещё до того, как «додумает» его до конца.

## Что вы получаете

**Общение**
- Переписка текстом с красивым Markdown: таблицы, жирный, код — агент оформляет ответы аккуратно
- Голосовые сообщения распознаются автоматически (локальный Whisper, русский язык, бесплатно и приватно — аудио не покидает ваш сервер)
- Фото, видео, файлы и стикеры — агент видит и понимает их содержимое
- Ответы приходят «потоком»: бот показывает черновик, пока дописывает финал

**Умные кнопки**
- Опасные команды агент подтверждает кнопками «Одобрить / Отклонить» — кнопки исчезают после нажатия
- Вопросы с вариантами ответа, выбор модели и другие пикеры — всё в один тап

**Богатые ответы**
- 📍 Точки на карте — «пришли геометку Эрмитажа»
- 🧸 Стикеры — «кинь мишку с сердцем»: агент знает набор «Мишка» и подбирает стикер по описанию
- 👤 Карточки контактов, файлы, картинки, видео и аудио
- Известные стикеры не гоняются через распознавание — бот уже знает, как они выглядят, и не тратит токены

**Работа в группах**
- В групповых чатах бот отвечает на упоминания и replies; в личке — всегда
- Управление группами: закрепление сообщений, участники, админы

**Автоматизация**
- Регулярные доставки по расписанию (cron) в выбранный чат
- Память per-chat: группа и личка не смешивают контексты

## Установка за 3 шага

Нужен установленный Hermes Agent и токен бота из кабинета
[«MAX для бизнеса»](https://business.max.ru/self) (Чат-боты → ⋮ → Настройки → копировать токен).

```bash
# 1. Установите плагин (любой способ)
hermes plugins install MrYadro/hermes-max-gateway/maxbot
#   или: git clone https://github.com/MrYadro/hermes-max-gateway.git \
#        && cp -r hermes-max-gateway/maxbot ~/.hermes/plugins/

# 2. Впишите токен и разрешённых пользователей
cat >> ~/.hermes/.env <<'EOF'
MAX_ACCESS_TOKEN=ваш_токен
MAX_ALLOWED_USERS=ваш_user_id
EOF

# 3. Перезапустите гейтвей
hermes gateway restart
```

Напишите боту в MAX — он ответит. Для голосовых сообщений один раз установите
`pip install faster-whisper` в окружение hermes (модель скачается сама).

## Настройка под себя

Основное меняется в `~/.hermes/.env`:

```
MAX_ACCESS_TOKEN=...        # токен бота (обязательно)
MAX_ALLOWED_USERS=123,456   # кто может писать боту
MAX_HOME_CHANNEL=-100...    # куда приходить cron-доставке
```

Продвинутое (опционально): режим webhook вместо polling, порт и секрет вебхука,
скрытие превью ссылок — переменные `MAX_UPDATES_MODE`, `MAX_WEBHOOK_URL`,
`MAX_WEBHOOK_PORT`, `MAX_WEBHOOK_SECRET`, `MAX_DISABLE_LINK_PREVIEW`.

Приватность: память у каждого чата своя. По умолчанию агент может читать прошлые
сессии вашего профиля по просьбе из любого чата — если это не нужно, скажите
ему «не используй session_search» или ограничьте тулсет в конфиге.

## Частые вопросы

**Бот молчит в группе?** — Бот должен быть администратором группы: так устроен
Bot API MAX, события приходят только админам.

**Ошибки сертификатов на Linux-сервере?** — Домены MAX используют российский
корневой сертификат. Положите корни в `/usr/local/share/ca-certificates/`,
выполните `update-ca-certificates` и добавьте в `~/.hermes/.env`:
`SSL_CERT_FILE=/etc/ssl/certs/ca-certificates.crt`.

**Почему при перезапуске гейтвея нет сообщения «Gateway online»?** — Оно приходит
только после плановых перезапусков (`/restart` из чата или обновление hermes).
Обычный `systemctl restart` молчит намеренно.

**Бот может поставить реакцию на сообщение?** — Пока нет: Bot API MAX не даёт
ботам реакций. Как только откроют — добавим.

**Что бот НЕ умеет отправлять?** — Опросы (poll) и «шеринг»-карточки ссылок:
платформа разрешает это только обычным клиентам.

## Возможности платформы (для любознательных)

| Входящие | Исходящие |
|---|---|
| текст, фото, видео, аудио/голосовые, файлы, стикеры, контакты, геометки, шаринг | текст (Markdown), фото, видео, аудио/голос, файлы, стикеры, геометки, контакты, кнопки |

Голосовые расшифровываются до передачи агенту — он сразу видит текст и не тратит
ходы на инструменты.

## Для инженеров

Специфика MAX Bot API, проверенная живыми запросами (2026-09):

| Что | Поведение | Как обходим |
|---|---|---|
| Upload медиа | хосты требуют curl-подобный multipart (`files=`, per-part `application/octet-stream`); у video/audio токен приходит сразу в `POST /uploads` (файл отвечает `retval`), у image/file — в ответе загрузки (топ-уровень или карта `photos`) | `maxbot/uploads.py` реализует оба пути |
| Стикеры | `payload.code` = **hex(id)** из набора; десятичный id → `not.found`; с текстом не отправить | каталог «Мишка» с описаниями от vision-модели; стикеры из каталога не гоняются через vision |
| Геометка | координаты — плоские поля вложения `latitude`/`longitude` (не в `payload`) | `Attachment` несёт плоские поля |
| Fenced-код в markdown | после кириллицы до ``` парсер MAX не находит закрывающий fence и «глотает» хвост сообщения | таблицы рендерятся строками в инлайн-код (моноширинно, выравнивание живёт при переносе) |
| `message_callback` | без объекта `message` | mid клавиатуры храним в состоянии; кнопки снимаются пустым массивом вложений |
| Группы | события только админу чата | назначьте бота админом |
| Вложения в апдейте | payload пуст | догрузка `GET /messages/{mid}` |
| `types` в GET /updates | `message_callback` не в дефолте | передаём явно |
| Реакции | API не даёт ботам | — |
| Опросы / share | отправка ботам запрещена | — |

```bash
git clone --depth 1 https://github.com/NousResearch/hermes-agent.git ../hermes-agent
```
